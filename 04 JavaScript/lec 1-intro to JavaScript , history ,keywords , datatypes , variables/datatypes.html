Data types in HTML

There are two types of datatypes present in JS

  • Primitive datatypes
  • Non Primitive Datatypes

There are 7 types of primitive datatypes

  • number
  • string
  • boolean
  • undefined
  • null
  • symbol
  • bigint

There are 3 types of non-primitive datatypes

  • function
  • object
  • array
