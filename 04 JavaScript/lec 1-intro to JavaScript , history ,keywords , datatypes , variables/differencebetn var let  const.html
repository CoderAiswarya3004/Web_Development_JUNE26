Difference between var let & const

  1. let & const are block scoped whereas var is function or global scope
  2. let & var can be reassigned, whereas const cannot be reassigned
  3. Redeclaration is possible in case of var keyword whereas redeclaration is not possible in case of let and const keyword
  4. if we try to access variables declared with var keyword before their declration then these variables value will be undefined, whereas if we try to access variable declared with let & const before there declaration then it will generate reference error(because values are present inside TMP - temporal dead zone)
